# System Guarantees — CURRENT et limites

Baseline `c14751f` (2026-10-03). **GUARANTEED BY CODE/SCHEMA** désigne une propriété bornée par les transactions et contraintes présentes ; **PROVEN BY TESTS** nomme seulement les scénarios couverts, sans preuve universelle. **MEASURED** exige une mesure reproductible publiée. **TARGET** et **NOT SPECIFIED** ne sont pas des garanties. Voir le [modèle fonctionnel](../product/Functional_Model.md) et l'[architecture](../architecture/Architecture.md).
