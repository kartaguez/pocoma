## What Is Included

This release marks the first shareable **Pocoma V3** reference baseline, delivering a complete, locally reproducible CQRS platform in **Java 21 / Spring Boot / PostgreSQL 17**:

- **5 isolated JVM runtimes** (`http-write`, `http-read`, `command-worker`, `results-worker`, `business-read-worker`) orchestrated with PostgreSQL 17.6, Keycloak 26.7.0 (OIDC Code + PKCE S256), Prometheus v3.5.0, and Grafana 12.3.2 via `./pocoma-local`.
- **42-module layered architecture** (`domain-*`, `contract-*`, `port-*`, `engine-*`, `orchestrator-*`, `supra-*`, `infra-*`, `compose-*`, `runtime-*`) verified by 50 ArchUnit rules (`architecture-tests`).
- **Pure-JDBC WRITE & READ persistence** (`pocoma_write` / `pocoma_read`), 36 L2 routing partitions, 30 s SQL leases with batched renewal (`renewBatch`) and strict fencing, exact rational arithmetic for pot balances, and atomic READ availability publication across 8 families.
- **Developer onboarding & verification tooling**: `./pocoma-local doctor`, `start`, `reload`, `status`, `stop`, `reset`, `destroy`, `bruno` (118 requests / 236 tests), `gui`, and scoped Maven slice verification (`scripts/testing/verify.py` + `docs/testing/Reactor_Verification_Policy.md`).

## Quick Start for New Developers

1. Check your workstation:
   ```bash
   ./pocoma-local doctor
   ```
2. Start a local instance and verify `READY`:
   ```bash
   ./pocoma-local start --instance demo
   ./pocoma-local status --instance demo
   ```
3. Run the automated end-to-end journeys or follow the manual walkthrough:
   ```bash
   ./pocoma-local bruno --instance demo
   ```
4. Follow the **30-Minute Onboarding Path** in [README.md](../../README.md) and [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Qualification Scope & Explicit Reserves

- **Certified locally (`CERT-FULL` on `f589d95c`)**:
  - Functional, security, architectural, and PostgreSQL 17 transactional compliance: **`1 173 / 1 173` Maven reactor tests `PASS`** (`0` failure, `0` error, `0` skip), **`50 / 50` `architecture-tests` `PASS`**, Bruno E2E **`118 / 118` `PASS`**.
  - Local performance characterized on Apple M4 Docker (6 CPUs / 5 376 MiB): nominal `1 cmd/s` `p95 = 146–160 ms`, sustained `35 cmd/s` `p95 = 134 ms` (single-host ceiling `36.83 cmd/s`), Large Pot `100/2 000` `p95 = 289 ms`, 10k backlog catch-up `129.8 s`.
- **Explicitly deferred to L8 / target production infrastructure (NOT certified locally)**:
  - `SPEC-09` Configuration A/B (`2 × 4 vCPU / 8 GiB` + isolated Keycloak), sustained `50 cmd/s` peak, `10k/1M` and `100k/10M` global volumes, multi-node HA failover, TLS/mTLS, secret rotation, and external third-party audit.
- **Platform reservation**:
  - `./pocoma-local` has been verified from a clean clone on **macOS (Apple Silicon / ARM64)** with Docker Desktop. Automated CI runs Maven + Testcontainers on **Linux (`ubuntu-24.04`)**. Local `./pocoma-local` execution on Linux and Windows (WSL2) has not been independently qualified yet.
