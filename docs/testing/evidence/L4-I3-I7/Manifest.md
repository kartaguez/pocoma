- P01-A…G/J/K : sources + stores I3 + conformité POT_VERSION + indépendance. H/I à I8. L : compteurs locaux, profils exhaustifs/SLO à L6.
- P02-A…J/L : nouveau source/store/participant ; variantes arithmétiques et WRITE d10/d11 réutilisées uniquement pour le calcul et l’autorité inchangés. K à I8 ; M : SQL local puis profils/SLO L6.

- I6 : EUI@V, monotonie, confidentialité interne et filtre physique User ; endpoint/authentification à I8/L5.
- A10-A…K : contributions internes listées ; égalité publique des codes/enveloppes, sessions même User et consentement restent I8/L5.
- CON-03…06 : conformité de chaque branchement, atomicité/readiness, recovery/UNKNOWN et capacité affectée. Claims/fencing/retry/quarantaine inchangés attribués aux preuves historiques ; aucune recertification du moteur.
