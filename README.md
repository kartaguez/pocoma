# Pocoma

Pocoma gère des pots partagés, leurs participants, leurs dépenses et leurs soldes. Les commandes et l’inscription sont admises puis traitées de façon asynchrone ; les lectures utilisent les résultats et projections matérialisés.

La [porte d’entrée documentaire](docs/README.md) distingue l’état livré, les cibles et les archives. Sources principales : [Functional Model](docs/product/Functional_Model.md), [Architecture](docs/architecture/Architecture.md) et [System Guarantees](docs/guarantees/System_Guarantees.md).

Pour l’exploitation et la vérification, voir les [runbooks](docs/operations/cmd-start-runtimes.md) et la [politique de vérification](docs/testing/Reactor_Verification_Policy.md).
